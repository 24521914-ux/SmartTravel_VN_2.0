External connector endpoint comes from source URI; only explicit host allowlist, HTTPS in production, no redirects, no embedded credentials. Source secret_reference is `none` or `env:NAME`; secrets are resolved from process environment, not persisted or returned as plaintext. Request deadlines and streamed response limits bound every body chunk; request and body each have a3s bound.

It seeds source30000000-0000-4000-8000-000000000001, original synthetic data under CC0-synthetic-v1, storage=true/training=false; no real external source was crawled. Set its URI via ingestion.fixture.uri to a fixture connector. MigrationV4 adds command/job/security helpers; V1-V4 remain immutable. V5 aligns source names/licenses with frozen 1024-character bounds; V6 widens raw/source-link identifiers to 1024 characters, and normalization accepts the same record-name bound.

Build `.\backend\mvnw.cmd -B -f backend/services/ingestion-service/pom.xml verify`, run the target jar, or `python backend/platform/build_service_image.py ingestion --tag smarttravel-ingestion:p01-local`. Image runs user10001 and contains no credentials. Compose runtime uses service DB/broker DNS, not host loopback. JSON logs/error messages redact connector/raw details. ## Pipeline, policy and recovery

Only one active job per source. FULL and INCREMENTAL use paged HTTP connector; REPLAY processes stored records. Canonical sorted JSON hash dedups identical raw records; changed hashes create immutable revisions. Normalize name/address/coordinates/VND/categories/opening hours; invalid data stays in quarantine with redacted reason. Present prices become finite nonnegative JSON numbers, including numeric source strings; missing/null prices remain unknown/null. Optional address is NFC-normalized with trimmed/collapsed whitespace and persisted in local normalized_payload only. Frozen upsert v1 permits no address, so outbound commands explicitly select its allowed fields; propagating address requires a later contract revision. Primitive connector rows use canonical wrappers with their original JSON type and retained licensed raw value, creating failed items without aborting valid rows; any failed item keeps the job PARTIAL and prevents checkpoint advancement. Job/item counters derive from persisted rows internally; frozen job responses intentionally expose no extra counter fields. Ground-truth scoring is fixture calibration, not production accuracy evidence. Existing source link takes priority; candidates need operator review, and ambiguous records never silently overwrite Catalog. Commands persist proposed UUID, command_id and expected Catalog version; replay retains them. Links only update after matching applied acknowledgment. Missing ack keeps RUNNING; failed items produce PARTIAL; checkpoint advances only after all required acks and no failed items. Absence from source never deletes a Catalog place.

Policy/allow_storage=false or REVOKED cancels work, blocks new raw ingestion and pending commands, and publishes the versioned policy event. Catalog protected-field rejection creates NEEDS_REVIEW; reviewers explicitly MATCH/CREATE/REJECT. Row/parent locks prevent concurrent duplicate accounting. Idempotency keys reused with another mode conflict. Deletion anonymizes operator identifiers and retains licensed public source provenance, then acknowledges the deletion request.

Outbox+audit/inbox mutation is transactional. Publish is persistent, confirmed and mandatory before marking delivered. Crash between publish and commit can redeliver the same ID; inbox dedup tolerates it. Listener retries3 before own DLQ. Eight publish failures stop automatic retry while retaining the row. Fix topology/connection/policy before `python backend/services/ingestion-service/ingestion-ops.py replay-outbox --event-id <uuid>`; replay records audit, preserves ID, disables workers/listeners/Flyway and binds only loopback. `replay-dlq` requires separate BROKER_OPERATOR_USERNAME/BROKER_OPERATOR_PASSWORD with only own DLQ read/inbound publish; original supported x-death routing is required, replay confirms before ack and malformed metadata remains queued. Avoid database resets/queue purges/source-place deletion as recovery. Local capture binds ingestion.# and domain.#; runtime cannot inject partner results. P02 connects actual Catalog/Intelligence/authorized sources; actual-source provenance quality is assessed in P03. Reviewer confirmation and remote CI are separate evidence.

Deletion concurrency: all human mutations acquire a per-user PostgreSQL transaction advisory lock before checking status/tombstone and locking domain rows. Identity deletion uses the same user lock, so it waits for an in-flight create/job to commit and purges or anonymizes it before publishing the acknowledgment. A latch-based real database regression verifies the uncommitted-insert case and blocks subsequent mutations by a deleted user.

V7 persists versioned Identity operator status. DISABLED/DELETED block admin mutation under the user fence; stale activation does not restore access and a newer ACTIVE version does. Unknown status remains permitted for explicitly isolated P01 fixtures. The registered status event is schema-validated, bound to the inbox and supported by original-routing DLQ replay; database and real broker regressions cover it.

Audit runtime UPDATE/DELETE/TRUNCATE revoked by additive migration V8. Deletion uses a restricted SECURITY DEFINER function with fixed search_path and no PUBLIC EXECUTE. Disposable test fixture cleanup uses migrator credentials; normal domain operations retain runtime credentials.
